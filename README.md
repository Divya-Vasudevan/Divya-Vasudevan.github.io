# Basic HTML/CSS/JS Starter

Open `index.html` directly in your browser or serve the folder with any static server. No build step required.

## Structure
- `index.html` — markup and layout.
- `styles.css` — global styles, layout, and theme toggle.
- `script.js` — tiny vanilla JS helpers.

## Quick start
1) Open the folder in your editor.
2) Double-click `index.html` to view it, or run a lightweight server:
   - Python: `python3 -m http.server 8000`
   - Node: `npx serve .`
3) Edit and refresh—changes are immediate.

## Notes
- Theme preference is stored in `localStorage` and can be toggled via the footer button.
- All assets are plain text—ideal for quick prototypes or teaching basics.
